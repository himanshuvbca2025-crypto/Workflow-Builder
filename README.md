# Workflow Builder

A visual Workflow Builder built using HTML, CSS and JavaScript.

## Features

- Add Workflow Nodes
- Drag & Drop Nodes
- Connect Nodes with Edges
- Delete Nodes
- Delete Edges
- Run Workflow
- DAG Detection
- Topological Sort Execution
- Responsive Design

## Technologies Used

- HTML
- CSS
- JavaScript

## How to Run

1. Download or clone the repository.
2. Open `index.html` in your browser.
3. Create nodes and connect them.
4. Click **Run Workflow**.
